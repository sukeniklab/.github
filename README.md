# Sukenik Lab

The Sukenik Lab studies how proteins interact with their environments, in cells and in vitro. The lab focuses on intrinsically disordered proteins and how environmental changes affect protein function.

Learn more on the [Sukenik Lab website](https://sukeniklab.com) and visit [Shahar Sukenik's Google Scholar profile](https://scholar.google.com/citations?user=MID9HCgAAAAJ&hl=en).
